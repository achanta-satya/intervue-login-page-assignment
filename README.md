## Intervue_Login_Page_Assignment
 QA Intern role assignment

This automation script logs into [Intervue.io](https://www.intervue.io) using Selenium and performs a few UI validations.

## 🔧 Technologies Used
- Python
- Selenium WebDriver
- ChromeDriver
- dotenv for handling sensitive info securely

## 🧪 Features Automated
- Login to Intervue.io
- Switched to new window
- Search for an interview
- Validate dashboard text
- Logout
